# Next.js 16 Starter with Tailwind CSS v4, shadcn/ui, and Recharts

A modern, production-ready Next.js 16 starter template with dark/light mode, color palettes, analytics dashboards, and comprehensive UI components.

## 🚀 Features

- **Next.js 16** - Latest Next.js with App Router and Turbopack
- **TypeScript** - Type-safe development
- **Tailwind CSS v4** - Utility-first CSS framework with CSS-first configuration
- **shadcn/ui** - Beautiful, customizable UI components
- **next-themes** - Seamless dark/light mode with system preference support
- **Color Palettes** - Multiple color schemes with persistence
- **Recharts** - Beautiful, responsive charts and data visualizations
- **TanStack Query** - Powerful data fetching and state management
- **Responsive Design** - Mobile-first with hamburger menu
- **Navigation** - Clean navigation with active states and route grouping
- **Dashboard** - Insights and Projections pages with real charts

## 📋 Prerequisites

- Node.js 18.17 or later
- npm, yarn, or pnpm


###  Clone the repository
https://github.com/touhid9xx/next-skeleton

### Install dependencies
npm install

npm run dev
